# 🏠 בית תלת־מימדי — Three.js

סצנה תלת־מימדית עצמאית (קובץ HTML יחיד) של בית מפורט, בנויה עם [Three.js](https://threejs.org/).

## מה יש בסצנה

- **בית דו־קומתי** — יסוד בטון, קירות, קרניז בין הקומות
- **גג רעפים משופע** עם גמלונים, שורות רעפים ורכס
- **ארובת לבנים** עם עשן מונפש
- **חלונות** עם מסגרות, אדנים ותריסי עץ + חלון עגול בגמלון
- **דלת כניסה** עם פאנלים, ידית, מדרגות וגגון על עמודים
- **מרפסת** עם מעקה בקומה העליונה
- **גינה** — עצים, שיחים, ערוגות פרחים, שביל מרוצף
- **גדר היקפית** עם שער ופנס רחוב
- **מצב יום / לילה** — ירח, חלונות מוארים, פנס ותאורת כניסה
- **בקרות מצלמה** — סיבוב, זום, הזזה וסיבוב אוטומטי (OrbitControls)

## הפעלה

פשוט פותחים את `index.html` בדפדפן (נדרש חיבור אינטרנט — Three.js נטען מ־CDN).

לחלופין, עם שרת מקומי:

```bash
cd 3d-house
python3 -m http.server 8000
# ואז לגלוש אל http://localhost:8000
```

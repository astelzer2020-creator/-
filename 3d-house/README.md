# 🏠 וילה ברוש — סיור וירטואלי תלת־ממדי

אתר סיור וירטואלי מלא בגוף ראשון בתוך בית דו־קומתי, בנוי עם **React Three Fiber + Three.js**.
המשתמש מתחיל בתצוגה חיצונית של הבית, לוחץ "התחל סיור", הולך בשביל, פותח את דלת הכניסה,
ומסייר חופשי בין כל החדרים — כולל עלייה אמיתית במדרגות לקומה העליונה.

## יכולות

- **שלושה מצבי תצוגה** — תצוגה חיצונית (Orbit), סיור חופשי בגוף ראשון, וסיור מודרך שמטיס את המצלמה לכל חדר במסלול בטוח דרך הפתחים (כולל פתיחת דלתות אוטומטית בדרך).
- **בית אדריכלי אמיתי בקנה מידה** — קומת קרקע (מבואה, סלון, מטבח, פינת אוכל, שירותי אורחים, גרם מדרגות) וקומה עליונה (חדר שינה ראשי + רחצה צמודה, שני חדרי שינה, חדר רחצה משפחתי, גלריה ופינת קריאה). תקרות 2.9 מ׳, דלתות פנים 0.86 מ׳, גובה עיניים 1.68 מ׳.
- **התנגשויות אמיתיות** — פותר קפסולה מול AABB עם החלקה לאורך קירות; אי אפשר לעבור דרך קירות, רהיטים, חלונות, מעקות או דלתות סגורות.
- **מדרגות פעילות** — שני מהלכים עם פודסט; הטיפוס והירידה חלקים (רמפת גובה + כבידה).
- **דלתות אינטראקטיביות** — E במחשב / כפתור "פתח דלת" בטלפון, אנימציית פתיחה סביב ציר שנפתחת תמיד מהמשתמש והלאה, עדכון התנגשות דינמי וצליל עדין (מסונתז, ללא קובצי אודיו).
- **בקרות מחשב** — WASD, עכבר עם Pointer Lock, ‏Shift לריצה, E לאינטראקציה, חצים למבט מהמקלדת, Esc לשחרור.
- **בקרות מגע** — ג'ויסטיק וירטואלי (שמאל), גרירת מבט (ימין), כפתורי אינטראקציה גדולים, safe-areas, תמיכה ב-portrait/landscape.
- **יום/לילה** — מעבר הדרגתי של שמיים, שמש, חשיפה ותאורת פנים/חוץ.
- **תוכנית קומה חיה** — מיני־מפה דו־ממדית (Canvas, ללא רינדור סצנה נוספת) עם מיקום, כיוון מבט והחלפת קומה אוטומטית.
- **נקודות מידע** — סמנים עדינים עם פרטי הבית, המטבח, המדרגות ועוד.
- **ביצועים** — כל הגיאומטריה ממוזגת ל-draw call אחד לכל חומר, עצים וגדרות ב-instancing, טקסטורות פרוצדורליות בלבד (אין נכסים חיצוניים), איכות אדפטיבית לפי המכשיר, הגבלת DPR, עצירת רינדור כשהלשונית מוסתרת.
- **נגישות ויציבות** — aria-labels, שליטה במקלדת, זיהוי חוסר תמיכה ב-WebGL, ‏Error Boundary וטיפול באובדן הקשר WebGL.

## התקנה והרצה

דרישות: Node.js 18 ומעלה.

```bash
cd 3d-house
npm install
npm run dev        # שרת פיתוח: http://localhost:5180
```

## Build לפריסה

```bash
npm run build      # תוצר סטטי בתיקיית dist/
npm run preview    # תצוגה מקדימה של תוצר ה-build: http://localhost:5181
```

התוצר הוא אתר סטטי לחלוטין (`base: './'`) — אפשר לפרוס את תוכן `dist/` על כל אחסון סטטי:
GitHub Pages, Netlify, Vercel, S3 או כל שרת קבצים.

## מבנה הקוד

```
src/
  house/
    plan.js         # מקור אמת: מידות, חדרים, קירות, פתחים, מדרגות, דלתות, גרף ניווט
    geometry.js     # הפיכת התוכנית לקופסאות תלת־ממד + גופי התנגשות
    furniture.js    # ריהוט פרוצדורלי לכל חדר
    exterior.js     # גינה, עצים, גדר, שביל
  components/       # House, Doors, Exterior, Lighting, InfoPoints,
                    # FirstPersonController, OrbitView, Experience
  ui/               # TourUI (עברית/RTL), MobileControls, FloorPlan, Help, Loading
  stores/           # tourStore (zustand) — מצבי תצוגה, דלתות, יום/לילה
  utils/            # collisions, cameraPaths (BFS), materials, audio, input, world
```

עיקרון מרכזי: `plan.js` הוא מקור אמת יחיד — הקירות, גופי ההתנגשות, המיני־מפה
ומסלולי הסיור המודרך נגזרים כולם מאותם נתונים, כך שאי אפשר שיסתנכרנו לא נכון.

## בדיקות

בדיקות E2E (Playwright) מכסות: טעינה ללא שגיאות Console, כניסה לבית דרך הדלת,
חסימת קירות ודלת סגורה, טיפוס מדרגות אמיתי, מעקה הגלריה, סיור מודרך לכל 14 החדרים,
מיני־מפה, יום/לילה, מובייל ברוחב 375px עם ג'ויסטיק, ורענון ישיר של העמוד.
